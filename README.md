## About Oblivion

Oblivion is an engineering organization focused on building intelligent systems across artificial intelligence, data engineering, and software engineering. The team works at the intersection of data processing, graph analysis, and digital twin technology, connecting BIM and Revit-based workflows with modern software architecture and computational design.

This repository is the official public identity hub of Oblivion. It introduces the organization's engineering focus, presents its featured systems — including **Orbital** and **Sentinel** — and documents its approach to research, tooling, and open development across artificial intelligence, computational architecture, and intelligent information systems.

Oblivion's work spans early-stage research, internal tooling, and applied engineering projects, with an emphasis on clear architecture, reproducible systems, and practical automation.

---

## Engineering Focus

Oblivion's work is organized around a set of core engineering domains:

| Domain | Description |
|---|---|
| Artificial Intelligence | Applied AI and machine learning for engineering and data problems |
| Data Engineering | Pipelines, structuring, and processing for large-scale data systems |
| Data Processing | Transformation, cleaning, and analysis of structured and unstructured data |
| Software Engineering | Core application, tooling, and systems development |
| Graph Analysis | Modeling and analyzing relationships within complex datasets |
| Digital Twins | Virtual representations of physical systems and environments |
| BIM / Revit | Building Information Modeling workflows and Revit-based tooling |
| Computational Architecture | Algorithmic and data-driven approaches to architectural design |
| Automation | Reducing manual effort across engineering and data workflows |
| Local AI | On-device and self-hosted AI systems |
| Intelligent Information Systems | Systems that structure, connect, and reason over information |

## Featured Systems

### ORBITAL

<img src="./assets/orbital-data-processing-platform.png" alt="Orbital data processing and graph analysis platform developed by Oblivion" width="640" />

Orbital is a data processing and graph analysis system developed by Oblivion. It is designed around structuring and connecting data for analysis workflows that rely on relationships between entities rather than isolated records.

*Detailed technical documentation is maintained in the Orbital repository.*

### SENTINEL

<img src="./assets/sentinel-information-platform.png" alt="Sentinel information platform developed by Oblivion" width="640" />

Sentinel is an information systems platform developed by Oblivion, oriented around structuring, organizing, and surfacing information within intelligent data systems.

*Detailed technical documentation is maintained in the Sentinel repository.*

### DTX-REVIT-VIEWER

<img src="./assets/digital-twin-revit-viewer.png" alt="Digital twin viewer for Revit-based BIM data developed by Oblivion" width="640" />

DTX-Revit-Viewer is a visualization tool developed by Oblivion for exploring digital twin data derived from Revit and BIM models, connecting computational architecture workflows with digital twin representations.

*Detailed technical documentation is maintained in the DTX-Revit-Viewer repository.*

## Research & Development

Research efforts inform the design of Oblivion's tools and are gradually formalized into documented, maintained systems.
